# Lessons Learned

Record only verified lessons that can save a future session from repeating a diagnosis or implementation mistake. This is project-specific operational memory, not a raw activity log.

Use an ADR for a durable architectural decision. Use this file when an observed failure has a verified cause and a practical prevention rule.

## Entry Format

### <YYYY-MM-DD> — <short lesson title>

- symptom: <what was observed>
- wrong assumption or failed path: <what led the work astray>
- verified cause: <evidence-backed cause>
- resolution: <what fixed it>
- prevention: <rule or check for future sessions>
- scope: <affected component, path, template, or environment>
